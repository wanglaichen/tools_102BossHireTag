# 小程序发版与部署说明

## 1. API 服务（Flask）

### 本地
```bash
./restart.sh start
# http://127.0.0.1:9212
```

### 线上（现有 Vercel 流程）
```bash
git tag v1.x.x
git push origin v1.x.x
```
GitHub Actions 会部署到 Vercel。

**注意：** Vercel 节点多在境外，国内小程序访问可能偏慢。若延迟明显，建议把 API 迁到国内云主机（同 Redis 区域更佳）。

### 生产环境变量（建议）
```env
REDIS_URL=rediss://...或 redis://...
MINIAPP_AUTH_REQUIRED=1
WECHAT_APPID=你的小程序AppID
WECHAT_SECRET=你的小程序AppSecret
CORS_ALLOW_ORIGINS=https://你的Web域名
# 不要在生产长期开启 MINIAPP_DEV_TOKEN
```

## 2. 微信小程序

### 开发
1. 微信开发者工具 → 导入项目 → 选择 `miniprogram/`
2. 填入真实 AppID（或测试号）
3. 详情 → 本地设置：勾选「不校验合法域名」（仅开发）
4. 修改 `miniprogram/utils/config.js`：
   ```js
   baseUrl: "https://你的API域名"  // 真机必须 HTTPS
   ```

### 正式发布前
在[微信公众平台](https://mp.weixin.qq.com/)配置：

| 类型 | 域名 |
|------|------|
| request 合法域名 | API 的 HTTPS 域名 |
| downloadFile 合法域名 | 同上（导出用） |
| uploadFile 合法域名 | 如后续需要再配 |

### 上传与提审
1. 开发者工具点击「上传」
2. 登录公众平台 → 版本管理 → 提交审核 → 发布

小程序版本号建议与 `APP_VERSION` / Git tag 对齐，便于排查。

## 3. 联调检查清单

- [ ] `GET /api/version` 正常
- [ ] 列表能拉到 Redis 数据
- [ ] 新增 / 编辑 / 删除成功
- [ ] 剪贴板导入 / 文件导入成功
- [ ] 导出 CSV/JSON 能打开或转发
- [ ] `MINIAPP_AUTH_REQUIRED=1` 时，无 Token 写接口返回 401
- [ ] 登录页 `wx.login` → `/api/auth/login` 成功拿到 Token

---

## 4. Web 与小程序并存

- Web：继续访问同一 Flask 站点
- 小程序：只调用 `/api/*`
- 跨域：服务端已支持 `CORS_ALLOW_ORIGINS`（小程序本身不走浏览器 CORS，但 Web 管理端跨域时需要）

---

## 5. 常见问题

**真机无法请求 localhost**  
换成已备案 HTTPS 域名。

**导出打不开**  
部分机型对 csv/json 预览支持弱，可转发文件到电脑打开。

**登录报未配置 WECHAT_***  
服务端补齐 `WECHAT_APPID` / `WECHAT_SECRET`；开发期可暂用 `MINIAPP_DEV_TOKEN` + 登录 code=`dev`（仅开发）。
