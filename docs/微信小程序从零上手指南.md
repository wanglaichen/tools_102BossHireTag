# 微信小程序从零上手指南

> 适合第一次做小程序的人。  
> 目标：搞清楚要申请什么账号 → 本地联调 → 配置 AppID/Secret → 提审发布 →（可选）Git 发版。

相关文档：
- 改造方案：`docs/微信小程序改造方案.md`
- 发版部署：`docs/小程序发版与部署说明.md`

---

## 0. 你需要准备什么（先看这张表）

| 东西 | 是否必须 | 说明 |
|------|----------|------|
| **微信小程序账号** | ✅ 必须 | 在微信公众平台注册，拿到 AppID |
| **小程序 AppSecret** | ✅ 正式登录必须 | 在公众平台生成，只放服务端 `.env` |
| **微信开发者工具** | ✅ 必须 | 电脑上预览/上传小程序 |
| **个人/企业主体** | ✅ 必须 | 个人可注册；企业提审类目更全 |
| **已备案 HTTPS 域名** | 真机/提审必须 | 本地开发可用 localhost（仅开发者工具） |
| **服务器（Flask API）** | ✅ 必须 | 本项目后端，本地或 Vercel/国内云 |
| **GitHub + Vercel** | 可选 | 只影响 API 自动部署，不影响小程序提审 |

一句话：  
**小程序前端靠微信账号；接口后端靠你自己的服务器；两边用 AppID/Secret 打通登录。**

## 1. 要去微信申请什么账号？

### 1.1 注册「微信小程序」账号（核心）

1. 打开：https://mp.weixin.qq.com/
2. 右上角点 **立即注册**
3. 选择账号类型：**小程序**（不是「公众号」「企业微信」）
4. 按提示完成：
   - 邮箱（未注册过微信公众平台）
   - 邮箱验证码
   - 密码
   - **主体信息**：
     - **个人**：用本人身份证 + 本人微信扫码验证（类目有限，但本工具一般够用）
     - **企业**：营业执照 + 法人/管理员验证（后续商用更稳）
5. 注册成功后登录公众平台后台。

> 注意：一个邮箱只能注册一个小程序；个人主体与企业主体权益不同。  
> 如果你只是自己用、先跑通，选 **个人** 即可。

### 1.2 你不需要先申请这些（容易混淆）

| 名称 | 要不要现在申请 |
|------|----------------|
| 微信公众号（订阅号/服务号） | ❌ 本项目不需要 |
| 微信开放平台（网站应用/移动应用） | ❌ 本项目暂不需要 |
| 微信支付商户号 | ❌ 当前功能无支付 |
| 企业微信 | ❌ 不需要 |

### 1.3 注册后你会得到什么

登录 https://mp.weixin.qq.com/ 后：

1. 左侧 **开发管理 → 开发设置**
2. 看到：
   - **AppID（小程序 ID）**：公开标识，可写进小程序工程
   - **AppSecret（小程序密钥）**：机密，只放服务器环境变量，**绝不能写进小程序前端代码、也不能提交到 Git**

如果没有 AppSecret：点「生成」/「重置」，用管理员微信扫码确认。

## 4. 配置真实 WECHAT_APPID / WECHAT_SECRET

### 4.1 从公众平台复制

1. 登录 https://mp.weixin.qq.com/
2. **开发管理 → 开发设置**
3. 复制：
   - AppID
   - AppSecret（没有就生成）

### 4.2 写到服务器 `.env`（不要写到小程序前端）

编辑项目根目录 `.env`（已被 `.gitignore` 忽略，不会进 Git）：

```env
WECHAT_APPID=你的AppID
WECHAT_SECRET=你的AppSecret

# 正式提审/上线建议打开鉴权
MINIAPP_AUTH_REQUIRED=1

# 生产不要长期开这个；开发可临时用
# MINIAPP_DEV_TOKEN=dev-local-token
```

同时把小程序工程里的 AppID 改掉：

`miniprogram/project.config.json` → `"appid": "你的AppID"`

### 4.3 重启后端

```bash
./restart.sh restart
```

### 4.4 登录链路说明

```
小程序 wx.login() 
  → 得到临时 code
  → POST /api/auth/login { code }
  → 服务器用 AppID+Secret 向微信换 openid
  → 服务器签发 Token
  → 小程序后续请求带 Authorization: Bearer <token>
```

没有 AppSecret，服务器无法向微信换 openid，正式登录走不通。

### 4.5 开发期临时方案（可选）

若暂时还没 Secret，可在 `.env` 设置：

```env
MINIAPP_AUTH_REQUIRED=0
MINIAPP_DEV_TOKEN=dev-local-token
```

并在 `miniprogram/utils/config.js`：

```js
devToken: "dev-local-token",
```

或登录时用开发 code（服务端约定）：仅本地调试，**提审前必须关掉**。

## 5. 准备提审前还要做什么？

### 5.1 服务器必须是 HTTPS + 可公网访问

微信正式环境不允许随意请求 IP / HTTP。

你需要：

1. 一个域名（建议已备案，国内主体更稳）
2. HTTPS 证书
3. 域名解析到你的 API（Vercel 自定义域名，或国内云 Nginx 反代 Flask）

把小程序里的地址改成：

```js
baseUrl: "https://api.你的域名.com",
```

### 5.2 在微信后台配置「合法域名」

路径：公众平台 → **开发管理 → 开发设置 → 服务器域名**

至少配置：

| 类型 | 填什么 |
|------|--------|
| request 合法域名 | `https://api.你的域名.com` |
| downloadFile 合法域名 | 同上（导出 CSV/JSON 需要） |

注意：
- 必须 HTTPS
- 不能带端口（443 除外）
- 不能是 IP
- 每月修改次数有限，先想好域名再填

### 5.3 完善小程序基本信息

公众平台 → **设置 → 基本设置**：

- 小程序名称
- 简介
- 头像
- 服务类目（个人主体可选类目较少，选接近「工具/信息查询」等）

### 5.4 隐私与用户协议（提审常问）

如果开了登录/读剪贴板/选文件，建议在设置或关于页写清：

- 会使用哪些权限（剪贴板、选文件）
- 数据存在你自己的服务器/Redis
- 用途是个人简历投递记录管理

并在公众平台按提示填写 **用户隐私保护指引**。

### 5.5 上传代码并提交审核

1. 开发者工具点 **上传**
2. 填写版本号（建议 `1.0.0` 或与 `APP_VERSION` 对齐）
3. 公众平台 → **管理 → 版本管理**
4. 选开发版本 → **提交审核**
5. 审核通过 → **发布**

审核一般要几小时到几天。被拒会写原因，按意见改再提。

## 6. Git 提交并发一版（API 侧，可选）

这是 **后端/网站** 的发版，和「小程序提审」是两件事：

| 动作 | 影响 |
|------|------|
| `git tag v*` 推送 | 触发 GitHub Actions 部署 Flask API 到 Vercel |
| 微信开发者工具「上传+提审」 | 发布小程序前端到微信 |

### 6.1 如果你要我帮你发 API 版，标准步骤是

```bash
# 1) 确认没有把 .env（含 Secret）提交上去
git status

# 2) 提交代码
git add miniprogram docs services app.py config.py env.example
git commit -m "feat: 增加微信小程序客户端与鉴权"

# 3) 推送
git push origin main

# 4) 打标签触发 Vercel
git tag v1.0.41
git push origin v1.0.41
```

### 6.2 千万别提交的内容

- `.env`（含 REDIS 密码、WECHAT_SECRET）
- 任何写死了 AppSecret 的文件
- 个人隐私数据 JSON

`.gitignore` 已忽略 `.env`，提交前仍建议再检查一次。

- [ ] Git 提交（不含密钥）

## 8. 费用与门槛（常见疑问）

| 问题 | 答案 |
|------|------|
| 注册小程序要钱吗？ | 个人/企业注册本身一般免费；认证企业号另说 |
| 一定要企业吗？ | 个人也能做工具类；企业类目和主体更正规 |
| 一定要备案域名吗？ | 正式请求合法域名通常需要合规 HTTPS 域名；国内访问建议备案 |
| 没有服务器行吗？ | 不行，本项目数据在你的 Flask+Redis，不是纯前端 |
| 只用 Vercel 行吗？ | API 可以；但国内网络可能慢，小程序体验受影响 |
