岗位采集接口

如何把招聘平台岗位写入「更新企业」

登录账号后携带 Token 调用 HTTP API。同渠道下「企业名 + 岗位名」唯一，重复提交会覆盖更新。

1登录拿 Token
2POST 写入岗位
3列表 / 统计查看

鉴权

先登录拿到 token，之后每个请求在 Header 里带上：

Authorization: Bearer <你的 token>
Content-Type: application/json

Token 来自登录接口 POST /api/auth/login 的返回字段，或浏览器登录后本地已保存的会话。

字段说明

channel招聘渠道，如 boss / liepin
company_name企业名称
job_title岗位名称
salary_min薪资最低（可选，数字，建议单位 K）
salary_max薪资最高（可选，数字，建议单位 K）
location地点地址（可选）
job_summary职位简介（可选）

薪资示例：salary_min: 15、salary_max: 25 表示 15-25K；也可传字符串 "15k"。若最低高于最高，服务端会自动对调。

唯一键 同一账号、同一 channel 下，对 company_name + job_title（忽略大小写）做哈希得到记录 ID。再次提交相同组合 → 更新；新组合 → 新增。

单条写入

POST /api/job-updates

{
  "channel": "boss",
  "company_name": "星云互娱",
  "job_title": "前端开发（React）",
  "salary_min": 15,
  "salary_max": 25,
  "location": "深圳·南山区",
  "job_summary": "参与企业投递台页面迭代，要求熟悉组件化与交互联调。"
}
curl -X POST "http://127.0.0.1:9212/api/job-updates" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d "{\"channel\":\"boss\",\"company_name\":\"星云互娱\",\"job_title\":\"前端开发（React）\",\"salary_min\":15,\"salary_max\":25,\"location\":\"深圳·南山区\",\"job_summary\":\"参与企业投递台页面迭代\"}"

批量写入

POST /api/job-updates/batch，body 里放 items 数组（也兼容 data）。顶层 channel 可作为默认渠道。

{
  "channel": "boss",
  "items": [
    {
      "company_name": "示例科技有限公司",
      "job_title": "Python 后端工程师",
      "salary_min": 20,
      "salary_max": 35,
      "location": "上海·浦东新区",
      "job_summary": "负责招聘工具后端接口开发与 Redis 数据落库。"
    },
    {
      "company_name": "星云互娱",
      "job_title": "前端开发（React）",
      "salary_min": 15,
      "salary_max": 25,
      "location": "深圳·南山区"
    }
  ]
}
curl -X POST "http://127.0.0.1:9212/api/job-updates/batch" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d "{\"channel\":\"boss\",\"items\":[{\"company_name\":\"示例科技有限公司\",\"job_title\":\"Python 后端工程师\",\"salary_min\":20,\"salary_max\":35}]}"

返回会汇总：新增 / 更新 / 跳过 条数。

查询与删除

GET /api/job-updates?channel=boss&q=关键词列表查询，可加 time_filter / from_ts / to_ts
DELETE /api/job-updates/<id>?channel=boss删除单条
POST /api/job-updates/clear清空（body 传 channel）
